# RV There Yet? — Трекер ачивок

Интерактивный трекер всех **96 ачивок** игры *RV There Yet?* 

## Открыть

**https://laugeed.github.io/rv-there-yet-achievements/**

## Возможности
- Прогресс-бар в реальном времени
- Мульти-фильтры (карта + сложность + статус одновременно)
- Поиск
- Сохранение прогресса в браузере (localStorage)
- PWA — можно добавить на экран «Домой» в Safari / Chrome

## Карты
- Mabutts Valley
- Mt. Yurbuttsk  
- St. Búttin Bay

Сделано для комьюнити RV There Yet?

# RV There Yet? — Трекер ачивок

Интерактивный трекер всех **96 ачивок** игры *RV There Yet?* с красивым дизайном, фильтрами, прогрессом и поддержкой PWA.

## Открыть сайт

**https://laugeed.github.io/rv-there-yet-achievements/**

## Возможности
- Прогресс-бар в реальном времени
- Фильтры по картам, сложности и статусу (можно комбинировать)
- Поиск
- Сохранение прогресса в браузере
- PWA — можно добавить на экран «Домой»

Сделано для комьюнити RV There Yet?
